# DisasterAgent：自然灾害领域多智能体系统

DisasterAgent 是一个基于 LangGraph 构建的自然灾害领域多智能体知识服务系统。

系统采用轻量级 Harness 运行架构，通过结构化任务规划、动态专家调度、执行约束、状态管理与结果评估，协调多个领域专家智能体完成复杂自然灾害知识问答任务。

系统集成 RAG（检索增强生成）、MCP（模型上下文协议）、NL2SQL（自然语言转 SQL） 等技术，支持法律法规检索、历史灾害数据查询、领域知识问答、应急科普与实时网络搜索。

## 架构概览

系统采用 Harness 运行架构 + 领域专家智能体 + 工具与资源接入层 的分层设计。

Harness 负责组织智能体的执行过程，包括任务规划、专家路由、执行控制、状态管理和结果评估；领域专家智能体负责完成具体领域任务，并通过模型推理、知识检索或外部工具调用获取所需信息。

### Harness 运行架构

系统基于 LangGraph 实现轻量级 Harness，通过以下机制管理多智能体协作过程：

| 核心组件                               | 功能描述                                                     |
| -------------------------------------- | ------------------------------------------------------------ |
| **Task Planner（任务规划器）**         | 解析复杂用户问题，生成结构化 JSON 子任务计划。               |
| **Orchestrator（运行编排器）**         | 根据子任务和已有执行反馈，动态选择领域专家智能体，组织任务执行。 |
| **Execution Controller（执行控制器）** | 通过结构化路由和轮次上限约束执行过程，避免无约束的重复调度。 |
| **State & Memory（状态与记忆）**       | 管理执行上下文与任务进度；计划扩展持久化检查点及跨会话长期记忆。 |
| **Evaluator（结果评估器）**            | 判断当前子任务是否完成，并结合执行反馈决定后续处理。         |
| **Answer Synthesizer（回答综合器）**   | 汇总多个专家的执行结果，生成最终回答。                       |

**规划扩展：Answer Reviewer（全局回答审核器）**

计划引入独立的全局回答审核模块，对最终答案进行事实一致性、证据充分性及任务完整性检查。审核未通过时，根据反馈执行有限次数的重新综合或补充检索，形成可控的审核反馈闭环。

### 核心工作流程

1. **任务规划**：Task Planner 分析用户意图，将复杂问题拆解为结构化子任务。
2. **运行编排**：Orchestrator 根据任务需求，动态选择合适的领域专家智能体。
3. **任务执行**：专家智能体通过大语言模型、RAG 或 MCP 工具获取专业信息。
4. **反馈与评估**：专家结果回传至执行上下文，Evaluator 判断子任务是否完成；必要时继续调度其他专家。
5. **回答综合**：所有子任务处理完毕后，Answer Synthesizer 汇总已有结果并生成最终回答。

后续将扩展全局回答审核与反馈机制，实现最终答案的质量检查及有限次修正。

### 状态与记忆机制

系统目前基于 LangGraph State 管理部分执行状态，并通过任务清单记录子任务完成情况。

后续计划完善三个层次：

- **Working Memory（工作记忆）**：统一管理对话上下文、子任务进度、专家反馈及执行结果。
- **Checkpoint（状态检查点）**：通过持久化检查点保存运行状态，支持会话恢复和中断后的继续执行。
- **Long-term Memory（长期记忆）**：存储经过筛选的跨会话信息，如用户偏好与常用领域知识。

其中，当前工作状态管理已有基础实现；持久化检查点和长期记忆仍属于计划扩展能力。

### 工具与资源接入

系统使用不同的技术通道连接外部知识与工具：

| 接入方式             | 主要用途                                           |
| -------------------- | -------------------------------------------------- |
| **Milvus + RAG**     | 法律法规与专业文档的混合检索、重排序及知识增强生成 |
| **MCP + NL2SQL**     | 自然灾害历史记录及结构化数据库查询                 |
| **MCP + Web Search** | 实时灾害动态、新闻与外部信息检索                   |

MCP 负责标准化工具调用，Harness 则负责协调智能体何时使用相应能力，以及如何处理执行结果。

## 专家智能体

| 智能体 | 能力 | 后端实现 |
|--------|------|----------|
| **法律法规智能体** | 中国灾害相关法律、法规、技术标准和应急预案 | RAG 管线，采用混合检索（通过 Milvus 实现稠密 + 稀疏向量检索）、重排序、相关性评分和幻觉检测 |
| **领域知识智能体** | 自然灾害成因、特征和分类的理论知识 | 基于 LLM 的问答 |
| **灾害记录智能体** | 结构化历史灾害数据查询（中国） | 通过 MCP 工具服务器实现 NL2SQL，覆盖地震记录、灾害损失、区域统计等 |
| **应急科普智能体** | 防灾减灾、应急响应指导和公共安全建议 | 基于 LLM 的问答 |
| **网络搜索智能体** | 实时网络信息检索，获取最新新闻、全球灾害数据和补充信息 | 通过 MCP 集成实现网络搜索 |

## 关键技术组件

- **LangGraph**：用于有状态、基于图的多智能体编排，支持条件路由
- **混合检索（RAG）**：由 **Milvus** 驱动的稠密（HNSW）+ 稀疏（BM25 风格）向量搜索，使用 **BGE-M3** 嵌入模型和 **BGE-Reranker-v2** 进行结果重排序
- **NL2SQL**：通过 MCP 工具服务器实现自然语言到 SQL 的转换，用于结构化灾害数据库查询
- **MCP（模型上下文协议）**：标准化的工具集成，用于网络搜索和数据库访问
- **多级质量控制**：RAG 管线内的文档相关性评分、幻觉检测和答案-问题对齐检查


## 技术栈

- **大语言模型**：Qwen2.5 系列（通过 vLLM / OpenAI 兼容 API 提供服务）
- **向量数据库**：Milvus
- **嵌入模型**：BGE-M3
- **重排序模型**：BGE-Reranker-v2-M3
- **框架**：LangGraph + LangChain
- **工具协议**：MCP（模型上下文协议）
